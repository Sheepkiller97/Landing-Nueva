# Landing El Método Día Uno - v5

Landing HTML lista para publicar en GitHub Pages.

## Contenido
- `index.html`: página principal.
- `assets/`: carpeta para imágenes u otros recursos locales.
- `.nojekyll`: evita el procesamiento de Jekyll.

## Publicar en GitHub Pages
1. Creá un repositorio y subí el contenido de esta carpeta (no el ZIP).
2. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
3. Abrí la URL que aparece en Pages (tarda ~1 minuto).

## Imagen del mockup
El mockup del ebook se carga desde su URL de Shopify. Si querés usar un archivo propio, guardalo como `assets/mockup.png` y reemplazá las 2 apariciones de la URL en `index.html` por `assets/mockup.png`.

## Dependencias externas
Tailwind CDN, Google Fonts e imágenes en Shopify: requiere conexión a internet.
